# ATG-INDUSTRIES

Este proyecto es una aplicación web interactiva que ofrece a los usuarios la capacidad de **diseñar, personalizar y gestionar sus propios modelos de autos**. La plataforma proporciona una experiencia completa, desde la selección de modelos y colores hasta el almacenamiento seguro de los diseños en una base de datos.

### Requisitos de Autenticación

> **Acceso Restringido:** Es un requisito obligatorio que los usuarios hayan iniciado sesión para poder acceder a las funcionalidades de creación y almacenamiento de diseños de autos. Si un usuario no está autenticado, será redirigido automáticamente a la página de inicio de sesión.

### Módulos Principales de la Aplicación

#### 1. Página de Bienvenida (Home)

* Es el punto de acceso principal de la aplicación.
* Incluye una barra lateral desplegable, convenientemente ubicada en el lado derecho de la pantalla, que permite a los usuarios iniciar sesión.

![Página de Bienvenida con Barra Lateral](https://github.com/user-attachments/assets/52d2d270-2554-48bd-8327-0553592b6e5f)

#### 2. Diseñador de Autos

Una vez iniciada la sesión, los usuarios pueden acceder a esta sección mediante el botón "Diseña tu auto". Aquí pueden personalizar su vehículo:

* **Selección de Modelo:** Elegir entre tres modelos de autos disponibles.
* **Personalización de Color:** Asignar el color deseado al vehículo.
* **Identificación:** Asignar un nombre único al modelo creado.
* **Almacenamiento:** Guardar el diseño final en la base de datos personal.

#### 3. Garaje Personal

Los usuarios pueden acceder a su colección de diseños desde un botón en la página principal o directamente desde la página del diseñador. El garaje muestra un resumen detallado de las creaciones guardadas:

* El nombre de usuario (`login`).
* El nombre asignado al diseño del auto.
* El modelo y color seleccionados.
* **Gestión de Diseños:**
    * Un botón para **eliminar** cualquier diseño de la base de datos.
    * Un botón para volver a la página anterior.
